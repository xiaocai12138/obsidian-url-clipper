# URL Clipper 更新说明（2026-04-01）

## 概览

本次更新重点解决了网页剪藏稳定性、正文提取质量、标题层级控制和可观测性问题。

## 主要更新

- 增强 XPath 兼容性，支持对旧路径格式进行兜底匹配。
- 新增页面抓取多候选回退策略，降低特定站点抓取失败概率。
- 新增 Picker 快照直出能力：在 CSS/XPath 模式下可直接使用选中元素的 HTML 进行剪藏，减少对远程请求的依赖。
- 增加剪藏全流程日志，成功和失败结果都会输出到控制台。
- 新增“显示结果弹窗”设置，可控制是否显示剪藏结果通知。
- 恢复并统一中文界面文案（主剪藏弹窗、选择器弹窗、设置项）。
- 新增 HTML 表格到 Markdown 表格转换规则。
- 新增标题编号转义修正，避免出现 `2\.` 这种标题格式。
- 新增标题前缀配置：一级、二级、三级标题可分别设置，默认 `#`、`##`、`###`。
- 新增标题层级自动上提：当正文中无 `h1` 时，会自动把最小标题级别上提到一级。
- 接入设置页到插件生命周期，确保可在 Obsidian 设置中直接配置插件。

## 用户可见行为变化

- 遇到 CSDN 等页面抓取受限时，使用“选择正文区域”后可直接基于选中内容完成剪藏。
- 标题输出格式更加稳定，可按个人习惯自定义一级/二级/三级标题前缀。
- 表格内容会尽量以 Markdown 表格形式输出，减少手工整理成本。
